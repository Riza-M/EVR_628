# EVR 628 Assignment 2: Data Wrangling

## Project Objective

This project focuses on cleaning, transforming, and exploring tuna catch data from the Inter-American Tropical Tuna Commission (IATTC). The project examines tuna catch patterns by year, species, and fishing gear using R.

## Repository Contents

* `data/raw/` — original tuna catch data from the Inter-American Tropical Tuna Commission (IATTC), including the `CatchByFlagGear` dataset
* `data/processed/tuna_clean.rds` — cleaned and processed tuna catch data
* `scripts/01_processing/data_processing.R` — R script for cleaning and processing the raw data
* `scripts/03_content/exploratory_data_visualization.R` — R script for exploratory data visualization
* `results/img/` — exported exploratory figures
